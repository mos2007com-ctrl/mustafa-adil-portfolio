# Mustafa Adil — Personal Portfolio

A bilingual Arabic/English portfolio built with Next.js, React, TypeScript, and Motion. The visual identity uses a warm ivory and muted sage palette with a custom network/workflow illustration.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm run start
```

## Personal details to add before publishing

The contact section intentionally does not invent personal contact details. Add the approved email, phone number, LinkedIn, and GitHub URLs when ready.

## Content notes

- The ICT diploma, CIS Lebanon AI diploma, Cisco AI certificate, Ministry training, and participation in AI/technology workshops are included as provided.
- The project cards summarize previously discussed work. Review the wording and remove or update any project that should not appear publicly.
- The site is Arabic-first with an English language switch.


The standalone `preview.html` includes an Arabic/English language switch and can be opened directly in a browser.
